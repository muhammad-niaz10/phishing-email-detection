# 🛡️ Phishing Email Detection System (NLP Academic Project)

This project was developed for a **University NLP Course** to detect phishing emails using basic Natural Language Processing and Machine Learning techniques.

### 🚀 Key Features
* **Text Preprocessing**: Lowercasing, regex cleaning, NLTK stop-words removal, and spaCy lemmatization.
* **Model Explainability**: Uses SHAP to highlight key words influencing the prediction.
* **FastAPI Backend**: Provides API endpoints for prediction.
* **Streamlit UI**: Simple frontend for pasting email text and viewing results.

### 🛠️ Tech Stack
* **Language**: Python
* **NLP Tools**: spaCy, NLTK
* **ML Libraries**: scikit-learn, SHAP, joblib
* **Web Frameworks**: FastAPI, Streamlit
